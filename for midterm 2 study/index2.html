  11. Q: Consider the following C program:

    #include <stdio.h>
#include <stdlib.h>

int main() {
    int *p;
    
    p = malloc(sizeof(int));  // 7
    
    if (p == 0) {
        fputs("ERROR: Out of memory\n", stderr);  // 10
        return 1;
    }
    
    *p = 42;
    printf("%d\n", *p);  // 15
    
    free(p);  // 17
    
    return 0;  // 19
}

    In which lines of this program will heap memory be allocated and/or deallocated?

    A: 7 and 17

     

  12. Q: ln which lines of this program are we referring to static memory?

    A: 10 and 15

     

  13. Q: ls the use of heap memory really necessary in the above program?

    A: No, since we're only allocation memory for one int. We could have used the stack for that.

     

  14. Q: How would the program's behavior change if we would remove line 17?

    A: The behavior wouldn't change,since the heap memory allocated in line 7 would be freed in line 19 when the process terminates.
